# Heart assets

The [Cardiac Atlas shared teaching source](Cardiac_Atlas_Animated/exports/shared-source-r01/README.md) owns the two current teaching exports. Edit their shared anatomy in the rigged [Cardiac Atlas source](Cardiac_Atlas_Animated/Cardiac_Atlas_Animated_Source.blend). The heart geometry, animated deformation and cutaway were authored procedurally in one frame.
