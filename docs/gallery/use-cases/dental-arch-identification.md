# Dental arch identification

A learner can choose a crown or an FDI label and identify the tooth, its arch and the patient's side. Open this lesson from Use Cases. It uses the original coverage receipt, crown coordinates, occlusal images and selector from the [owning lesson](../../../lessons/arch-identification/README.md).

Arrow keys follow the screen order in each arch. Home and End select its endpoints. Each arch keeps its selection when the learner changes arch or language. A missing image leaves every covered FDI number selectable. Keep source credits and coverage limits beside the viewer. [Route contract](../routes-and-api.md#page-links)
