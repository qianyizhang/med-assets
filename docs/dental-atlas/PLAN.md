## Acceptance

| Gate | Evidence |
| --- | --- |
| Source | Version, license, hashes, units, native relationships, preparation state, measured and authored features. Missing access, rights or morphology blocks the outcome. |
| Editable sequence | Common frame, named shot and exclusions, independent edit targets and preserved unaffected shape. Reuse suitable instruments. |
| Review | Clean reimport, matched overview/detail, decoded motion, repeat/reset/interruption, sampled clearance and state/deposit progression. Sampling establishes only sampled states. |
| Delivery | [Component contract](README.md) and [set/condition review](set-review.md). Preserve source, masters, licenses, applicable failed trials and evidence. Keep technical, visual, dental/anatomical, runtime and publication decisions independent. |
