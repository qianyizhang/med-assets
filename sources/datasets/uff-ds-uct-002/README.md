## Bounded method

1. Verify archive hashes. Read only the native ROI from source TIFFs; preserve source index order and offset.
2. Select intensity > 80, then the largest 6-connected hard-tissue region.
3. Fill holes per 2D slice, subtract hard tissue, then select the largest 6-connected space proxy. This is algorithmic selection, not expert labeling.
4. Extract 0.5 isosurfaces; convert source column/row/slice to metric XYZ. Correct closed-surface orientation without changing vertex positions.
5. Per-island source-endpoint QEM with topology, boundary, normal, float32-degeneracy and bounds guards. Retry at 75% or retain original if 50% fails. No island deletion.
6. Measure both directions using virtual-triangle coverage and point-to-triangle distances. Guard PCU singleton batches with the naive distance fallback.

The slice-space method omits the open terminal channel and produces an algorithmic cap. It is not complete pulp/canal reconstruction. Source/selection negatives are part of the candidate, not defects to conceal with generic repair.

- **Verified published-candidate tier:** pinned GLB hash, independent geometry/image checks and source identities.
- **Clean numerical replay tier:** the self-contained recipe regenerated byte-identical corrected master and display GLBs from the pinned source ZIP. [Replay receipt](replay-verification.json) records exact hashes. Final input/output-directory guards were added afterward and passed 7 tests plus candidate verification; no second full numerical run is claimed.

From repository root, in a separate working environment:

```bash
python -m pip install -r tools/dental/requirements-uff.txt
python tools/dental/uff_tomo1b.py all \
  --source-zip /path/to/ds-uct-002_root_canal_strain_tomo1b_20um_8bits.zip \
  --work-dir /path/to/uff-replay
python tools/dental/uff_tomo1b.py verify \
  --model models/dental_specimens/uff_tomo1b/exports/r01/uff-tomo1b-display.glb \
  --work-dir /path/to/uff-verification
python -m unittest discover -s tests/dental -p 'test_uff_tomo1b.py'
```

The CLI never downloads, accepts terms, signs in or publishes. Obtain the exact public ZIP separately. `all` runs ingestion, extraction, LOD and verification. Both commands require a new, nonexistent work directory and reject bad input before creating it; existing work is never overwritten. Intermediate masks/ROI/master stay in the supplied work directory. Expect several GB of transient memory and multi-minute geometry checks; no performance guarantee. Stop on source/hash or geometry errors rather than silently changing the recipe.
