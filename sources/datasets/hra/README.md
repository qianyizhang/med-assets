# Human Reference Atlas source inputs

The source records, licenses and checksums stay with their packages. Ten original GLBs used for replay are stored together in the [HRA recovery ZIP](../../../transport/README.md#restore-an-archived-collection). Run `python3.12 transport/tools/restore_collection.py hra-replay-sources` before a recipe or independent audit that reads these originals. The command restores the original paths and hashes. Maintained teaching exports remain available through the [family list](../../../docs/gallery/maintained-models.md).
