# Shared atlas frame

Raw OBJ millimetres are converted to glTF metres as `(x,y,z) -> (0.001x,0.001z,-0.001y)`. No per-organ recentering, displacement, mirroring or cross-atlas registration is claimed. Context anatomy shown in review images is excluded from each gland GLB. Keep these native-frame assets separate from mixed-source default assemblies.
