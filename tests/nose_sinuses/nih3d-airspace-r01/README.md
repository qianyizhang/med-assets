# Replay (external pinned inputs)

Dependencies actually used: Blender4.3.2 (bundled NumPy), Python3 + Pillow, DejaVu Sans for comparison text. These dependencies are not bundled; no installation is performed. No network access occurs in scripts. Fetch only the two public inputs recorded in `sources/nose_sinuses/nih3d-airspace-r01/provenance.json`, then verify their exact hashes/bytes.

Run from the package root; `SOURCE` is downloaded NIH workflow STL, `BASELINE` is the original authored GLB, and all output directories must be new. Approximate build5s, render5views~60s, independent verifier~5s.

```sh
T=tests/nose_sinuses/nih3d-airspace-r01
R=reviews/nose_sinuses/2026-10-26-nih3d-airspace-r01
C=models/nose_sinuses/exports/nih3d-airspace-r01/nasal_airspace.glb
blender -b --python-exit-code 1 --python "$T/build.py" -- --source "$SOURCE" --out new-build
blender -b --python-exit-code 1 --python "$T/export_verify.py" -- --source "$SOURCE" --candidate "$C" --record "$R/export-record.json" --out new-check
blender -b --python-exit-code 1 --python "$T/render.py" -- --baseline "$BASELINE" --candidate "$C" --out new-renders
python3 "$T/compose.py" --renders new-renders --out new-evidence
```

Build source hash, render baseline/candidate hashes and new-output guards fail closed. Independent verifier checks source and recorded output hashes, then inverse display transform, oriented topology and retained known defects. This is not exhaustive intersection detection, clinical verification or browser runtime QA. Native PNGs are generated by replay; selected lossless WebP images in review retain the same decoded pixels. Composite panels are resized annotations, not native evidence. Exact cross-version pixels are not promised.
