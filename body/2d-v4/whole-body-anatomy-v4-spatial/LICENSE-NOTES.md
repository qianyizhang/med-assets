# Artwork and reference rights

This package combines reference-informed original head/torso drawings with newly drawn support/tissue/pelvis artwork conservatively attributed as Servier adaptations. No reference bitmap, traced source path or clinical scan is bundled.

Adapted from Servier Medical Art by Les Laboratoires Servier, licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ . Contours, proportions, composition, colors, layering and tissue details were redrawn into new SVG geometry for this atlas. Per-asset source titles, source URLs and adaptation relationships are recorded in artwork-provenance.json, source-relationships.json and license-registry.json. Keep attribution and modification notices with adapted assets.

OpenStax was used only for anatomical fact validation; its current CC BY-NC-SA 4.0 text, figures and source geometry are not reproduced. Head/torso reference-image licenses describe those external references; reference-only use is distinguished in the registry. OHSU archival artwork is not reproduced and no reuse permission for it is claimed. Source creators do not endorse this package.

This private deliverable does not declare a new public license for the independent original portions. Decide that license separately before a public redistribution. Educational schematics and renderer QA are not clinical certification.
