# Single lymph node teaching edition

Use the exact-color tissue edition and two section planes for regional localization. Retain the form exemption for fine medullary relief and the capsule aperture.

Keeping all 114,498 encoded triangles and four separate tissue primitives preserves the medulla crevices that failed the earlier contraction check. Re-encoding the exactly constant color attributes saves 687,480 bytes (23.0%). The matched capsule, exposed tissues and reverse medulla are pixel-identical.

The capsule and tissue regions remain identifiable. Two source-mesh sections resolve the region silhouettes across depth, but show fine irregular medullary loops where there is no linked specimen annotation. The capsule aperture likewise lacks a registered identity. Filling these features could imply an intact capsule or erase a regional interface.
