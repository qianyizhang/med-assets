# Adrenals — scoped BP3D study

Left/right adrenal exterior silhouettes and same-source localization relative to kidneys. Kidneys are review context, not part of the gland export; illustrative color is not tissue evidence.

This migration preserves the existing reviewed bytes and selected display evidence. It is not a new study or broader anatomy approval. Existing baseline failures remain unchanged. Context structures are review-only and excluded from the gland GLB.

## Source and limitations

BodyParts3D, © Database Center for Life Science (DBCLS), CC BY 4.0 under the retained current official license. Raw OBJ historical CC BY-SA 2.1 Japan headers are not erased. Official source archive: external **64,888,505 bytes**, pinned SHA/member map at `sources/datasets/bp3d-4.0-glands/external-source-members.json`; no automatic download. The mutable LATEST URL is not an availability guarantee.

CAD atlas exterior, not a patient scan. Native mm-to-m proper-axis conversion, coordinate seam handling and illustrative smooth shading/materials are documented changes, not recovered tissue detail. No centering, clinical registration or default mixed-source assembly replacement.

Exact accepted GLB storage is verified; portable or byte-identical regeneration is **not established**. Frozen build scripts have layout/global mapping assumptions, so this PR does not present them as working replay tools. Historical topology diagnostics do not constitute new watertight proof. Native PNGs/scenes/full history are deferred; included WebPs preserve their own hashes and original-image bindings. Anatomy and intended-consumer runtime remain unapproved.
