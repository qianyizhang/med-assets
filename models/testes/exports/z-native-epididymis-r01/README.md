# Native testis–epididymis gross-form study

[Download the static GLB](testicular-region.glb) ·
[Matched visual evidence, checks and limits](../../../../reviews/testes/2026-10-30-native-epididymis/README.md)

Four named source objects: `Testis.r`, `Testis.l`, `Epididymis.r`, `Epididymis.l`.
Native effective transforms and source render subdivision are retained. Display
colors are illustrative: tan testis, rose epididymis. No ductus deferens,
scrotum or internal anatomy is supplied. Source names/laterality remain source
labels, not clinical validation. This is a limited supplement to `draft_testes`,
not a replacement for a complete organ/tract model.

SHA-256: `e35457062c7bba79d938700beab7de851c75fa8dbbbbc76872d47290f2833d0d`;
220,184 bytes; 14,304 triangles; no animation. Source-derived geometry and renders
retain [Z-Anatomy CC BY-SA 4.0 and full attribution](../../../../sources/datasets/z-anatomy/testicular-region/ATTRIBUTION.md).
No anatomy/clinical, functional-lumen, physical-scale or viewer-runtime approval.
