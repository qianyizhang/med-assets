# Eye order teaching selection

Use the [matched eye views](../../../../reviews/teaching-assessments/target-risk/views/eye.webp) to locate the transparent cornea in front, the iris around the pupil opening and the lens behind it. The three-structure file has 44,301 triangles and is 2,594,032 bytes. It preserves the source coordinates, retained accessor bytes and materials. The inherited angular open rim is visible in close-up.

The [exact diagnostic export](../hra-v1.3-r01/anterior_segment.glb) retains all seven structures, including the four ciliary and zonular meshes omitted from this study. The omission is editorial. The anatomy task covers broad anterior order. Corneal dimensions, optics, accommodation and attachment anatomy require separate evidence.
