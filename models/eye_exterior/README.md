# Globe and extraocular course supplement

This additive static study exposes the source's separate long extraocular courses,
trochlear turn and retained optic segment around each globe envelope. It supports
the bounded whole-eye exterior follow-up in #150. The original schematic and the
independent anterior-segment assets/#99 delivery remain separate and unchanged.

Open [the teaching sheet](../../reviews/eye_exterior/2026-10-30-z-native-courses-r01/presentation/teaching.svg)
or its [PNG](../../reviews/eye_exterior/2026-10-30-z-native-courses-r01/presentation/teaching.png).
Numbers identify source-named features across unilateral oblique and posterior views;
the image crop never removes a selected surface. L/R follows the source suffixes.

The [GLB](exports/z-native-courses-r01/eye-exterior-courses.glb) retains all 20
evaluated source surfaces (35,884 triangles, 674,580 bytes). It has two glTF scenes:
**Source R exterior courses** is default; **Source L exterior courses** contains
the other ten objects. Select a scene in a viewer that supports scene selection.
Blender 4.3.2 imports both scenes into one scene; select or hide objects by their
`.r`/`.l` source suffix for the documented unilateral views. Native coordinates
are retained, so neither side is moved to the origin. Browser scene-selection
behavior and performance remain unverified.

Both optic segments are retained in full. Displayed together, they can appear to
meet in the source geometry; that is **not validated pathway continuity**. The
teaching views show each separately and mark the retained source end. No chiasm,
attachment, muscle action, anterior-layer or clinical claim is made. Cornea and
sclera use the same opaque neutral envelope material; the original action-labelled
muscle shaders are preserved only as source metadata.
