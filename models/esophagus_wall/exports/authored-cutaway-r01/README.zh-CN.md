模型用五个独立命名网格表示**四层管壁**：黏膜、黏膜下层、外肌层（分内环行与外纵行两部分）、外膜。纵向楔形剖切让管壁的层次及折叠的腔面可见。这是教学补充，**不替代原始完整食管模型、两个管腔端部示意或其被动呼吸运动动画**；原动画本身也不代表蠕动。

## 示意范围
1. **黏膜**：上皮、固有层及黏膜肌层合并表示，未分别建模；非角化复层扁平上皮的细胞结构未重建。
2. **黏膜下层**：仅表示结缔组织区域；省略腺体、血管及黏膜下神经丛。
3. **内环行肌层**：外肌层的内层。标注说明典型纤维环绕管腔排列，但未重建单条肌纤维。
4. **外纵行肌层**：外肌层的外层。标注说明典型纤维沿长轴排列，但未重建单条肌纤维。肌间神经丛及各段骨骼肌/平滑肌比例差异均未表示。
5. **外膜**：本模型限定为胸段的结缔组织外层，不表示腹段浆膜或胃食管交界。

各层厚度比例、折叠数量、节段长度和配色均为教学设定，不是患者影像、实测组织切片或病理模型。两端及纵向90度楔形缺口是人为剖切，并非正常解剖开口、创伤或括约肌。模型不模拟蠕动或生理性开合。封闭且流形的网格仅表示几何分区，不等于生物组织不可渗透或真实管腔已获验证。

## 可复现与检查
```
python tests/esophagus_wall/replay.py --output /path/to/NEW-output-directory
# 可选：改变教学设定参数，输出到另一个全新目录
python tests/esophagus_wall/replay.py --params tests/esophagus_wall/parameters.json --output /path/to/another-NEW-directory
```
程序拒绝覆盖任何已有输出目录。依赖 Blender 4.3.2、Python 3、Pillow、DejaVu Sans 与 Noto Sans CJK 字体。默认参数可逐字节复现受检 GLB；改变参数得到的是未经复核的新教学变体，不会自动获得解剖验证。

`build-receipt.json`、`reimport-receipt.json`记录确切 GLB 哈希及各层有限坐标、正体积检查及 **1e-8 米容差焊接后的边诊断**（并非精确索引拓扑或流形证明）。所有原始 PNG 均来自清空场景后重新导入该 GLB 的渲染。`review-record.json`保留分项状态：技术检查只覆盖所列项目；组织层次仅经教学参考核对，不能据此判定完整解剖、临床用途或浏览器运行通过。

覆盖计数：**完整器官新增数为0**。本成果获准作为教学补充集成。保留的 PNG 已无损去除元数据，并逐字节验证解码像素一致；原始哈希保存在审查目录的 `png-metadata-receipt.json`。
