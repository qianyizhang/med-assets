# Maintained rebuilds and their owners

The selected rebuilds below resolve through the asset packages and the shared [GLB and rendering toolkit](../../../lib/med_assets). Run [the recipe dependency gate](../../../tools/verify_recipe_dependencies.py) through `tools/verify.py` or directly with Python 3.12. It checks the known command and data paths, confirms owner declarations match documented entry points, and validates declared source and output identities on hydrated files or LFS pointers. The build commands check the actual outputs.
