name: review-teaching-asset
description: Rebuild, compare, or promote a reviewed med-assets teaching export for a named learner task.
---

Start with the export owner's README and the task in its accepted assessment. Choose the view that exposes the claimed relationship and a second view that could reveal a misleading join or occlusion. Use the package's declared input, output and camera settings for replay. Compare exact bytes for a promised exact export, decoded geometry or pixels when that is the owner's contract, and the learner's action in the supported viewer.

For a new decision, attach the comparison, attribution, remaining limitations and any exemption to the exact export/task record. Use the [promotion command](../../../docs/guides/teaching-assessments.md) to preview the effect on the maintained choice and its alternatives. Apply the reviewed plan and check the generated views through the [ordinary gate](../../../docs/WORKFLOW.md#verification).
