name: rehearse-gallery-release
description: Qualify a candidate or frozen med-assets Gallery build, or inspect its retention and recovery obligations during a migration.
---

Build the intended selection using the [Gallery bootstrap](../../../sites/anatomy-gallery/README.md#restore-and-build-locally). Compare the catalog, exact model, evidence and receipt through its generated Worker and the local preview. Exercise the learner action with the resource available and missing. Use the two-origin release check for candidate/public selection changes. Compare required reads, optional local media, public index entries and admitted writes separately.

For a proposed retirement, run `python3.12 tools/verify.py retained PATH` to identify known consumers. Trace any unaccounted packaging or external reader before acting. Rehearse restoration with the [collection command](../../../transport/README.md#restore-an-archived-collection) and check exact old URLs when their backing changes. Record the tested revision and verified recovery locator with the owning work item. Local rehearsal and public release have separate authorization.
