# Male urethra in source context / 男性尿道同源背景

## What improved / 改进
- The old isolated tube did not show its relation to adjacent organs. The source-preserved assembly makes the gross bladder–prostate–spongiosum relationship visible.
- 原草稿只有孤立弯管；同源组合更清楚地展示膀胱、前列腺、尿道海绵体与尿道的大体位置关系。
- Transparency is a diagnostic display aid, not tissue appearance. The comparison uses different models/poses/framing and is not registered or scale-matched.
- 透明仅用于显示内部关系，不是组织外观；两模型姿态和取景不同，未经配准或等比例匹配。

## Not resolved / 尚未解决
- A single uncapped source curve surface is not a validated lumen or measured wall. Proximal connection and distal protrusion/outlet remain unvalidated; no flow, patency or functional claim.
- 单层、两端开放的来源管面不等于已验证管腔或实测管壁；近端连接、远端突出与开口未验证，不代表通畅性或功能。
- Source glans edge defects are retained. No blind repairs, invented connections or source-frame mixing.
- 保留来源龟头网格的边缺陷；未盲目修补、虚构连接或混合坐标系。
- Kidneys, ureters and a complete pelvic floor/sphincter system are absent. This is not the complete urinary tract, a clinical model or a full-organ pass. The original baseline remains Needs revision; count delta0. Existing2D teaching aid unchanged.
- 未含肾、输尿管及完整盆底/括约肌系统；不是完整泌尿道、临床模型或整器官通过。原草稿仍需修订，计数变化0；原2D教学图不变。

## Exact artifact roles
`urethral-context.glb` is the only packaged model:6 source objects, with Urethra as focus and5 native context components. The replay additionally emits an isolated urethra GLB for diagnostic rendering; it is deliberately not duplicated as a second downloadable candidate. The context is justified by spatial relationships, not a second penile-component pass.

Selected media: annotated context, model comparison, translucent oblique and isolated oblique. WebPs are lossless RGB conversions of exact-GLB imported PNGs; encoded PNG equality is not assumed. Rendered labels are separate overlays, not modified anatomy. Original opaque/source-only views remain reproducible but are omitted to limit duplication.
