# Failure → diagnosis → change → retest

1. **Original draft_blood:** plate-like plasma backing, button-like RBCs, and externally protruding nuclear beads. Exact old export/screenshots were inspected; no speculative reconstruction of its generation process is claimed. **Change:** a separately named authored study with no plasma slab, closed biconcave RBCs, and a connected nucleus fully enclosed in the intact cell. **Retest:** exact-export front/oblique/back, neutral, side and profile evidence. **Lesson:** a file loading correctly did not make the old anatomy teaching representation adequate.
2. **r01 render failed:** this Blender build lacks OpenImageDenoise support. **Change:** disabled denoising and retained the failure log. **Retest:** successful 32-sample Cycles CPU renders, honestly identified as no-denoise. **Lesson:** renderer capability is a technical prerequisite, not a geometry verdict.
3. **r01 topology diagnostic initially counted material seams as holes:** primitive-local counts were misleading. **Change:** assemble all material primitives of each mesh, then remap exact coordinate tuples (no tolerance welding). **Retest:** complete-mesh boundary count zero. One genuinely zero-area cut-face triangle remained. **Lesson:** primitive partitions are not anatomical boundaries.
4. **r01 cut-plane degeneracy:** the plane coincided with authored sphere vertices. **Change in r02:** move the pedagogical cytoplasm cut from y=0 to y=0.02, leaving intact model/nucleus unchanged. **Retest:** no anatomical zero-area triangles; later annotation problems remained separate.
5. **r01/r02 nucleus looked like three connected balls:** root visual critique, compared with the CDC smear. **Change in r03:** unequal elongated ellipsoids with smooth fixed low-order bending, no random noise or added organelles. **Retest:** same intracellular placement, continuous connecting necks, one connected component, identical intact/cutaway nuclear geometry, useful cutaway side view. **Lesson:** connectedness alone is not adequate visual form quality.
6. **Text-cap triangles:** exported labels in r02–r04 had collinear, zero-area triangles. Simple BMesh cleanup recreated ngons, and exporter triangulation reintroduced the problem. **Change in r05:** explicitly inspect triangulated loop faces and retriangulate each degenerate collinear cap with its neighbour, preserving glyph silhouette. **Retest:** 81 meshes / 179,596 triangles, zero degenerate triangles, zero exact-coordinate boundary and non-manifold edges. **Lesson:** inspect final exported indices, not only the editable scene.
7. **CDC comparison could misidentify the arrowhead:** root verified the official caption; the arrowhead indicates a lymphocyte, not the lower neutrophil. **Change:** explicit “Lower segmented cell: neutrophil. Arrowhead: lymphocyte (not modeled)” under the unchanged source image. **Retest:** corrected comparison pixels personally viewed; model hash unchanged. **Lesson:** figure labels/captions need the same reference review as geometry.
8. **Rebuild is not byte-identical:** canonical SHA `4c7c738b3ca6ae6cc7e44a449be0f7d26d04ceb9975e43d3b834a2caad96618c`; replay SHA `548417b8f3eff1e89e230ec3010f7e2452ea98f83f7e9627469d80ff49b4e75e`. **Diagnosis:** at matched node/material/triangle-corner semantics, POSITION, NORMAL, winding, node transforms/extras and materials match exactly. Only unused cutaway UV values differ by at most 5.96e-8, causing different vertex/accessor storage. No texture/image/COLOR data are used. **Retest:** fresh RBC render pixels match exactly; fresh cutaway render differs in one RGB channel by one 8-bit step out of 2.7 million channels. Canonical repeat pixels match exactly. The rebuild difference is therefore not claimed to lie within an observed nonzero repeat variation. **Lesson:** declare geometry/shading equivalence evidence and tiny rendering difference, not byte reproducibility. The reviewed canonical export is not replaced with the rebuild.
