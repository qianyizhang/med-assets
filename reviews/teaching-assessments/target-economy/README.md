## Recover the exact editions

Start at the repository root. The maintained GLBs are under the `path` entries in [editions.json](editions.json). Use a hydrated checkout and Blender 5.2.3 LTS Release Candidate `fab76e95306d` for geometry replay. Use Python 3.12 and Pillow 13.0.0 for texture repacking and plate composition.

1. For the same-scene mesh variants, run the [TAQ-012 recipe](../refinement-economy/README.md#build-or-recover-a-local-option) with `--only NAME --no-render` for each required trial name from [editions.json](editions.json). Recover skin and marrow using their owner recipes linked from that same section. Check the generated byte count and SHA-256 against the edition entry. The matched plates and full per-part measurements stay with TAQ-012 because the edition bytes are identical.
2. For all four exterior projections, run the following command in a fresh scratch directory. The replay matches the hydrated originals by digest, repacks only retained accessor ranges, independently decodes and verifies the retained data, then compares the exact clean imports at fixed cameras.

   ```sh
   blender --background --factory-startup --disable-autoexec --threads 6 --python-exit-code 1 \
     --python reviews/teaching-assessments/target-economy/projection.py -- \
     --out .artifacts/taq-015-projection-replay
   ```

   Each task directory contains `candidate.glb` and the source and updated renders. [Projection settings](projections.json) name each deliberate omission. The [projection receipt](projection-measurements.json) records hashes, retained and omitted meshes, camera bindings and decoded pixel differences. Matched views reuse the original cameras when the trial had two relevant whole/exterior directions. The HRA pair uses an additional neutral posterior view for both control and candidate to inspect its five lobar groups.

3. For the s1233 texture repack, use the following command. [Texture results](lung-textures.json) include the encoded size and exact decoded identity for each texture. [Render results](lung-render.json) bind the clean-import image pair.

   ```sh
   python3.12 reviews/teaching-assessments/target-economy/lung-textures.py \
     --out .artifacts/taq-015-lung-replay
   blender --background --factory-startup --disable-autoexec --threads 6 --python-exit-code 1 \
     --python reviews/teaching-assessments/target-economy/sweep.py -- \
     --out .artifacts/taq-015-lung-render --only lung_left --repacked-lung .artifacts/taq-015-lung-replay
   ```

## Tested alternatives and retained controls

The [follow-up trials](followup-measurements.json) retain per-part measurements and reported failures. The [settings](sweep-settings.json) use shorter edge limits and named protected bands from the original target. These additional trials test what can be gained before reducing the scene scope or leaving an exception. Run them from `sweep.py` in a fresh directory under `.artifacts`. The spinal cord trial returns a byte-size failure after writing its receipt, without emitting a replacement.

For liver, muscle atlas, brain, spinal cord and trachea, [the task decisions](decisions.json) record the economy exception, allowable teaching action and exact reopening condition. The original scores and approved assessment digests stay attached to the source files. For the liver, the protected-band follow-up rejected a 2.60-pixel change from the capsule before reducing below the useful saving threshold. For muscle, the earlier equivalent trial preserved the inspected groups but saved only 0.7% in encoded bytes with the existing buffer layout. The finer-edge brain trial saved 4.7% and did not expand the tested fold views. The spinal cord guard rejected the combined cord and descending-root trial's byte count. The gentler trachea band trial did not reach a useful reduction while protecting the thin band tips and preserving the exact shell.
