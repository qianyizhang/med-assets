## Replay and verification

The [dental section recipe](dental-sections.py) verifies the FDI31 NRRD against the [SWIRendo source map](../../../sources/datasets/swirendo-pilot/source-map.json) and UFF files 0965–0975 against their [member identities](../../../sources/datasets/uff-ds-uct-002/selected-members.csv). Supply these files in one scratch directory; name the unchanged FDI member `fdi31.nrrd`. `python dental-sections.py INPUT OUTPUT` writes the two plates and [section measurements](dental-sections.json). Distances summarize the named section samples, including the acquired edge. They are independent of the previous mesh-to-mesh comparisons. Python dependencies are NumPy, Pillow, SciPy and scikit-image.

For [ventricle sections](ventricle-sections.py), pass the pinned original [BP3D PART-OF archive](../../../sources/datasets/bp3d-4.0-glands/external-source-members.json) then a scratch output directory. The recipe verifies the archive and member FJ1730 before processing. Each section uses a native y plane through the original target GLB and the third-ventricle OBJ without fitted transforms. [Archive, member and measurements](ventricle-sections.json)

For the [protected bone trial](fdi-bone-trial.py), run `python fdi-bone-trial.py SCRATCH` in the pinned UFF Python environment, with the verified FDI31 NRRD in that directory. The [measurements](fdi-bone-trial.json) record changes to all three native sections.

For complete matched 3D replay, place the accepted ovary edition as `ovary.glb` and the verified BP3D archive as `bp3d.zip` alongside the bone trial’s `fdi-bone.glb` in that scratch directory. From the repository root run Blender 5.2.3 with `--background --factory-startup --disable-autoexec --python-exit-code 1 --python reviews/teaching-assessments/reopen-source/context-trials.py -- trial SCRATCH --materials`. This produces clean-import studio frames and the [camera, distance and contact record](context-trials.json). [Material cameras and source/updated frames](material-frames.json) use the predecessor’s fixed Cycles rig in [capture_ovary](../target-form/render.py). [Plate composition](compose.py) takes the captures directory and a fresh output directory; working PNGs and public source downloads stay in scratch. The bounded dental gate passed seven tests including actual pinned GLB bytes. The ovary recipe repeated the delivered bytes.
