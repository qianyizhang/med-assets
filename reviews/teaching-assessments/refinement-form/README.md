## Replay the images and geometry

Run from the repository root with the exact hydrated inputs. The images were made with Blender 5.2.3 LTS Release Candidate `fab76e95306d` and Python 3.12 with NumPy 2.2.6, Pillow 11.3.0 and libwebp 1.5.0. The replay requires unused output directories. The selection renderer takes the output directory in both positional slots to satisfy the prior wave's camera module initializer. The selection workflow updates visibility, camera or illustrative colors in a disposable scene. The native Workshop is inspected through an evaluated mesh snapshot so inherited scene state cannot obscure the intended selection.

```sh
pack=reviews/teaching-assessments/refinement-form
scratch=.artifacts/taq-011-replay
python3.12 "$pack/surface-trials.py" "$scratch/models"
blender --background --factory-startup --disable-autoexec --threads 4 --python-exit-code 1 \
  --python "$pack/render-selections.py" -- "$scratch/selection" "$scratch/selection"
blender --background --factory-startup --disable-autoexec --threads 4 --python-exit-code 1 \
  --python "$pack/render-trials.py" -- "$scratch/models" "$scratch/trials"
python3.12 "$pack/compose-plates.py" "$scratch/selection" "$scratch/plates" --trials "$scratch/trials"
blender --background --factory-startup --disable-autoexec --threads 4 --python-exit-code 1 \
  --python models/thyroid_ct_s0189/recipes/check_export.py -- --root . \
  --candidate "$scratch/models/thyroid-trial.glb" \
  --expected-sha256 6bc4f4da8bc91a058da8f9c78fca8618e3ace90580cac499adf48981bc18608e \
  --out "$scratch/thyroid-integrity.json"
```
